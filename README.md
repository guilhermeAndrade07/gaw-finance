# 🏦GAW Finance

O GAW Finance é um sistema de gestão financeira, nele você pode ter um controle das suas finanças para poder alcançar seus objetivos.

## 🧾Funcionalidaes
  - Home com saldo total, entradas do mês, saídas do mês e últimas transações;
  - Dashboard mostra o saldo total, entradas do mês, saídas do mês, e gráficos de fluxo de caixa mensal e despesas por categoria;
  - Cadastro de categorias, bancos e pagamentos a realizar;
  - Cadastro das entradas de dinheiro por mês;
  - Cadastro das saídas de dinheiro por mês

## ⚙ Tecnolias utilizadas
 - Python -> Linguagem Principal
 - Django ->  Framework web de alto nível
 - Django Rest Framework ->Criar APIs Web 
 - Bootstrap -> Framework CSS
 - PostgreSQL -> Banco de dados
